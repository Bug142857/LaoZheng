## 四、建议

1. **优先做免费聚合站**：九五小说、玄幻阁先补测详情 / 目录 / 正文，通过后按现有「固定模板」方式接入，和蚂蚁文学并列。
2. **第二批再试**：69书吧、笔趣阁⑲、笔趣阁7、衍墨轩；这些站点资源更全，但需要补 `@textNodes`、`##` 正则等规则能力。
3. **正版站（17K / 梧桐七猫 / 晋江 / 轻之文库）**：搜索页可用，但正文可能有 VIP / 登录限制，建议放在最后，或只做搜索入口不做下载。
4. **不建议直接执行合集里的 JS 书源**：1872 个源依赖 JS，执行任意远程脚本有安全风险，兼容成本也高。
5. 若以后想导入大量源，再考虑做「Legado 兼容层」：只支持无 JS 的 CSS / JSON 规则，批量实测后把可用源导入；预计仍会有不少站点失效。
6. 如果嫌 29 源 / 14 站里的免费源太少，下一批免费候选是：69书吧、顶点小说、笔趣阁⑲、笔趣阁7、衍墨轩、中意文学、久久小说、天地中文网、维基阅读、连尚读书。它们超出了当前「简单规则」筛选，需要额外支持 `@textNodes`、`##` 正则、JSONPath 等语法后再逐个实测。
